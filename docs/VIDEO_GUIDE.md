# دليل إعداد ومعالجة الفيديوهات (Video Guide)
## منصة Critical Ease — دليل الإجراءات السريرية

يشرح هذا الدليل المتطلبات التقنية والخطوات اللازمة لإعداد مقاطع الفيديو التعليمية، وحرق العلامة المائية لشعار **Critical Ease**، ورفعها عبر لوحة التحكم ضمن حدود باقة Mux المجانية.

---

## 1. مواصفات الفيديو (Video Specifications)

- **الملكية والهدف:** فيديو تعليمي واحد مخصص لكل إجراء.
- **الحماية ومنع التحميل:** الفيديوهات غير قابلة للتنزيل المباشر من المتصفح، ويتم بثها حصرياً عبر بروتوكول HLS المشفر برمز وصول رقمي مؤقت (Signed Playback Token).
- **منع نسخ MP4:** يتم تعطيل توليد روابط MP4 المباشرة (`mp4_support: "none"`) على خوادم Mux.
- **الصيغ المدعومة والحد الأقصى للحجم:** `MP4`, `MOV`, `WebM` بحد أقصى **500 ميجابايت** للملف الواحد قبل الرفع.
- **الحد الأقصى للمكتبة (Quota):** **10 فيديوهات كحد أقصى** وفق حدود الباقة المجانية.

---

## 2. حرق العلامة المائية وضغط الفيديو بواسطة FFmpeg (Watermarking)

لضمان بقاء شعار المنصة ظاهراً حتى في حال تسجيل الشاشة أو اقتصاص الإطار، يجب حرق العلامة المائية وضغط المقطع بدقة `720p H.264` قبل الرفع.

### أ. استخدام السكريبت الآلي (TypeScript Tool):
```bash
# تشغيل السكريبت الآلي على الفيديو المصدر
npx tsx scripts/watermark.ts <path/to/input.mp4> [<path/to/output.mp4>]

# مثال تطبيقي
npx tsx scripts/watermark.ts raw-videos/procedure.mp4 public/videos/procedure-watermarked.mp4
```

### ب. أمر FFmpeg القياسي:
```bash
ffmpeg -y -i input.mp4 -i public/brand/watermark.png \
  -filter_complex "[0:v]scale=-2:720[scaled];[scaled][1:v]overlay=W-w-24:24[outv]" \
  -map "[outv]" -map 0:a? \
  -c:v libx264 -preset veryfast -crf 22 \
  -c:a aac -b:a 128k \
  -movflags +faststart output.mp4
```

### المعايير الهندسية للأمر:
1. `scale=-2:720`: ضبط الارتفاع على `720p` تلقائياً مع الحفاظ على التناسب والأبعاد الزوجية (متوافق مع تشفير H.264).
2. `overlay=W-w-24:24`: تثبيت العلامة المائية في الزاوية العلوية على بعد 24 بكسل من الحافة، بعيداً عن شريط التشغيل السفلي.
3. `-c:a aac -b:a 128k`: ترميز الصوت بصيغة AAC بمعدل `128k` لضمان التوافق عبر المتصفحات والهواتف.
4. `-movflags +faststart`: نقل بيانات الفهرس (`moov atom`) لبداية الملف لتسريع بدء البث.

## 3. خطوات الرفع عبر لوحة التحكم (Upload Steps)

1. ادخل إلى لوحة التحكم الإدارية عبر `/admin`.
2. اختر الإجراء المستهدف، ثم انتقل إلى تبويب **"الفيديو"**.
3. إذا لم يكن هناك فيديو مرفوع، اضغط **"رفع فيديو جديد"** واختر الملف المعالج.
4. أثناء الرفع يظهر شريط التقدم واسم الملف مع زر **"إلغاء الرفع"** بارتفاع لا يقل عن 44 بكسل.
5. بعد اكتمال الرفع، تنتقل الحالة إلى **"قيد المعالجة"** ثم **"جاهز للعرض"** بمجرد انتهاء معالجة Mux.

---

## 4. سياسة سقف الـ 10 فيديوهات (10-Video Free Plan Limit)

- تفرض باقة Mux المجانية حداً أقصى يبلغ **10 فيديوهات** نشطة.
- عند بلوغ العداد `10 / 10` يُحظر رفع فيديو لإجراء جديد لا يملك فيديو سابقاً، مع السماح باستبدال فيديو إجراء حالي أو حذف فيديو لإجراء آخر، ويقوم الخادم بحذف الفيديو القديم من Mux تلقائياً عند الاستبدال أو الحذف.
